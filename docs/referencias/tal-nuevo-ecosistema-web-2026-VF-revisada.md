Nuevo ecosistema web
Contenido, estructura y tono para la nueva web de The Admissions Lab

Objetivo
Que la web se sienta más cercana, ágil e innovadora; menos como una consultora tradicional y más como un espacio que acompaña a las personas a construir un perfil internacional.
Este documento contiene el copy sugerido, CTAs, estructura de secciones y notas para desarrollo.

NOTAS VISUALES PARA DESARROLLO
• Mucho espacio en blanco y bloques cortos.
• Fotos del equipo grandes, naturales y con personalidad.
• Hover/tap en equipo para revelar “Mi superpoder / Fuera de TAL / Algo que siempre digo”.
• Microanimaciones suaves; evitar efectos pesados.
• Cards simples y modernas; no saturar de texto ni iconografía.
• CTAs claros y repetidos: “Quiero descubrir mi ruta”, “Explorar Study/Career/Skills/Community”.
• La sensación general debe ser: cercana, optimista, internacional y muy humana.
